# React MUI Admin Dashboard

A modern admin dashboard built with **React 19** and **Material UI (MUI) v7**, featuring interactive data tables, charts, and a full calendar view.

🔗 **Live Demo:** [dashboard-react-and-mui.web.app](https://dashboard-react-and-mui.web.app/)

## ✨ Features

- 📊 Interactive charts (bar, line, pie, and geo maps) powered by Nivo
- 📋 Advanced data tables with sorting, filtering, and pagination
- 📅 Full calendar with drag-and-drop event management
- 🎨 Clean, responsive Material UI design system
- 📝 Form handling with validation

## 🛠️ Tech Stack

**Frontend**
- [React 19](https://react.dev/)
- [Material UI (MUI) v7](https://mui.com/) — `@mui/material`, `@mui/icons-material`
- [MUI X Data Grid](https://mui.com/x/react-data-grid/) — advanced tables
- [React Router v7](https://reactrouter.com/)
- [React Hook Form](https://react-hook-form.com/) — form validation

**Data Visualization**
- [Nivo](https://nivo.rocks/) — Bar, Line, Pie, and Geo charts

**Calendar**
- [FullCalendar](https://fullcalendar.io/) — day grid, time grid, and interaction plugins

**Networking & Tooling**
- [Axios](https://axios-http.com/) — HTTP client
- [Vite](https://vitejs.dev/) — build tool
- [ESLint](https://eslint.org/) — code linting

**Hosting**
- [Firebase Hosting](https://firebase.google.com/products/hosting)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Ahmed-Esawy-1/Dashboard-MUI.git

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
